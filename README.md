# RealiTLScanner.sh

Порт [XTLS/RealiTLScanner](https://github.com/XTLS/RealiTLScanner) на Bash. Ищет TLS-серверы, которые подходят как `dest` для Xray REALITY: TLS 1.3, ALPN `h2`, в сертификате есть CN и организация издателя.

Флаги, логи и CSV такие же, как у Go-версии. Вывод сверялся с собранным оригиналом на одних и тех же целях.

## Зависимости

- `bash` версии 4.3 или новее и `openssl` версии 1.1.1 или новее (обязательно)
- `timeout` из coreutils (желательно; если его нет, используется запасной вариант на чистом bash)
- `getent`, `dig` или `host` для DNS
- `curl` или `wget` для `-url`
- `mmdblookup` (пакет `mmdb-bin` / `libmaxminddb`) или `python3` для GeoIP

Работает на Linux, macOS (bash из Homebrew) и в Git Bash на Windows. В Git Bash домены резолвятся через `nslookup`, а процессы запускаются медленнее, поэтому стоит поднять `-thread`.

## Использование

```bash
chmod +x RealiTLScanner.sh

# Справка
./RealiTLScanner.sh

# Сканировать IP, CIDR или домен
./RealiTLScanner.sh -addr 1.2.3.4
# Если addr — это IP или домен, включается бесконечный режим: ip, ip-1, ip+1, ip-2, ...

# Список целей из файла (по одной на строку)
./RealiTLScanner.sh -in in.txt

# Собрать домены со страницы и просканировать их
./RealiTLScanner.sh -url https://launchpad.net/ubuntu/+archivemirrors

# Порт (по умолчанию 443), подробный вывод, файл результатов (по умолчанию out.csv)
./RealiTLScanner.sh -addr 1.2.3.0/24 -port 443 -v -out file.csv

# Число параллельных потоков (по умолчанию 2) и таймаут на одну проверку (по умолчанию 10 с)
./RealiTLScanner.sh -addr 107.172.1.1/16 -thread 10 -timeout 5

# Включить IPv6 в дополнение к IPv4
./RealiTLScanner.sh -in in.txt -46
```

### Вывод

В терминале результат выводится цветной таблицей. Пока идёт сканирование, под таблицей обновляется строка статуса: сколько адресов проверено, сколько подошло, время и текущий адрес. В конце печатается итог: сколько адресов проверено и сколько подошло. Итог печатается и после Ctrl+C. С `-v` видны и неподходящие адреса с причиной (например, `not suitable: ALPN http/1.1`). Флаг `-raw` включает исходный формат логов RealiTLScanner. Он же используется сам, когда вывод перенаправлен в файл или в другую программу. Цвета можно отключить переменной `NO_COLOR=1`. Формат CSV не меняется.

### Проверка DNS и proxy-site

По умолчанию для каждого подходящего адреса скрипт резолвит домен из сертификата. Результат выводится в колонке `DNS CHECK`. Если домен указывает на этот же IP или на его /24 (для IPv6 на /48), строка зелёная, а в колонке написано `matches IP`. Если домен живёт на других адресах или вообще не резолвится, строка жёлтая, в колонке написано `proxy-site`, а после стрелки указано, куда домен ведёт на самом деле. Обычно это чужой REALITY или SNI-прокси, который пересылает сертификат настоящего сайта. Для своего `dest` такие адреса брать не стоит.

Пометка есть только в терминале. В CSV попадают все подходящие адреса, как в оригинале, а `-raw` печатает логи без изменений. Ответы DNS кешируются, поэтому на скорость проверка почти не влияет. Отключить её можно флагом `-check-dns=false`.

```
RealiTLScanner · -addr 144.31.182.166 · port 443 · 2 threads · timeout 10s · DNS check: on · CSV: out.csv
    IP               CERT DOMAIN                     ISSUER                    TLS      ALPN  CURVE           GEO   DNS CHECK
  ✔ 144.31.182.140   example-host.de                 Let's Encrypt             TLS 1.3  h2    X25519          DE    matches IP
  ↪ 144.31.182.166   www.otto.de                     DigiCert Inc              TLS 1.3  h2    X25519          DE    proxy-site → 3.66.105.53

Stopped in 1m2.3s · checked 120 · suitable 1 · proxy-site 1 · saved to out.csv
```

Лучше запускать локально: сканирование с VPS может привести к тому, что хостер пометит сервер.

### GeoIP

Положите базу MaxMind GeoLite2/GeoIP2 Country в текущую папку под именем `Country.mmdb`, например [отсюда](https://github.com/Loyalsoldier/geoip/releases/latest/download/Country.mmdb). Поиск идёт через `mmdblookup`. Если его нет, используется встроенный читатель на `python3`.

## Формат результата

```csv
IP,ORIGIN,TLS,ALPN,CURVE,CERT_LENGTH,CERT_SIGNATURE,CERT_PUBLICKEY,CERT_DOMAIN,CERT_ISSUER,GEO_CODE
1.2.3.4,example.com,TLS 1.3,h2,X25519,2728(certs count: 3),SHA256-RSA,RSA,example.com,"Let's Encrypt",US
```

## Отличия от Go-версии

- Каждая проверка запускает отдельный `openssl s_client`, поэтому на сотнях тысяч закрытых адресов скрипт медленнее бинарника. На реальных сетях скорость в основном зависит от `-timeout` и `-thread`.
- `X25519MLKEM768` предлагается, только если локальный OpenSSL версии 3.5 или новее. С более старым OpenSSL сервер с постквантовым обменом покажет в `CURVE` значение `X25519`. Ответ `feasible` от этого не меняется.
- `-timeout` ограничивает всю проверку целиком (подключение и рукопожатие). В Go на подключение и на рукопожатие отводится по `timeout` отдельно.
- Текст ошибок DNS и HTTP в подробном логе берётся из системных утилит, поэтому может отличаться от Go.
- В Go-версии последняя найденная строка иногда не успевает попасть в CSV перед выходом. В скрипте строка пишется сразу.
